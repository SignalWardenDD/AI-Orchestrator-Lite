## 📁 **СОЗДАННЫЕ КОНФИГУРАЦИОННЫЕ ФАЙЛЫ:**

### 1. **`config/symbols.yaml`** - ✅ ГОТОВ

- **Реальные параметры Binance USDT-M** (tick_size, step_size)

### 2. **`config/settings.yaml`** - ✅ ОБНОВЛЕН
- **ML интеграция** - полные настройки моделей
- **Signal providers** - все 4 аналитика
- **Guards** - Edge-Guard, конверсии, Real-Time Re-Check
- **Execution** - PostOnly LIMIT, market fallback
- **Risk Management** - лимиты, стоп-дни
- **Telemetry** - логирование, отчеты, метрики

### 3. **`config/risk.yaml`** - ✅ ОБНОВЛЕН
- **Position sizing** по группам символов
- **Risk filters** - calm market, volatility spike, correlation
- **Daily/Weekly limits** - лимиты убытков
- **Emergency stops** - аварийные остановки

### 4. **`config/ladders.yaml`** - ✅ ОБНОВЛЕН
- **TP лесенка** - 4 уровня по спецификации
- **Break Even уровни** - денежные BE после TP
- **SL множители** по типам сигналов
- **Trailing stops** - настройки трейлинга

## ⚙️ **КЛЮЧЕВЫЕ НАСТРОЙКИ:**

### **ML Интеграция:**
```yaml
ml:
  enabled: true
  model_path: "forecast/models/binary_hit_ADAUSDT_and_6_more_H24.joblib"
  calibrator_prefer: "isotonic"
  prob_weight_base: 1.0
  prob_weight_gain: 1.0
```

### **Risk Management:**
```yaml
risk:
  daily_loss_usdt: -7.5
  weekly_max_neg_days: 3
  max_positions_per_symbol: 1
  max_total_positions: 7
```

### **TP/SL Лесенка:**
```yaml
tp:
  - { pct: 0.20, atr_mult: 0.6 }    # TP1: 20% @ +0.6×ATR
  - { pct: 0.25, atr_mult: 1.2 }    # TP2: 25% @ +1.2×ATR
  - { pct: 0.25, atr_mult: 2.0 }    # TP3: 25% @ +2.0×ATR
  - { pct: 0.30, atr_mult: 3.2 }    # TP4: 30% @ +3.2×ATR
```

### **Break Even уровни:**
```yaml
be:
  after_tp1_usdt: 0.15    # entry + fees + 0.15 USDT
  after_tp2_usdt: 0.35    # entry + fees + 0.35 USDT
  after_tp3_usdt: 0.80    # entry + fees + 0.80 USDT
```
